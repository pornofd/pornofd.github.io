## 📋 Overview

drift-kafka is a handy command-line tool designed for Apache Kafka users. It helps you capture the current state of your Kafka cluster and detect drift during incidents. Whether you are a system administrator or just someone looking to monitor your Kafka setup, drift-kafka simplifies the process.

## 🛠️ Features

- **Read-Only Access**: Ensures safe and secure data collection from your Kafka cluster.
- **Easy Detection of Drift**: Helps you quickly identify inconsistencies in your cluster state.
- **User-Friendly Interface**: Simple command-line operations for everyone.
- **Compatibility**: Works with different Kafka setups and configurations.

## 💻 System Requirements

To run drift-kafka, ensure your system meets the following requirements:

- **Operating System**: Supports Windows, macOS, and Linux.
- **Java**: Requires Java 8 or higher installed.
- **Memory**: Minimum of 512 MB RAM recommended.
- **Disk Space**: At least 100 MB of free space required.

## ⚙️ Usage Instructions

After running the application, you can use it with several commands. Here are some essential commands to get you started:

- **Capture Cluster State**: Use the following command to capture your cluster's state:
  ```
  drift-kafka capture
  ```

- **Detect Drift**: Check for drift in your Kafka configuration with this command:
  ```
  drift-kafka detect-drift
  ```

- **Help Command**: If you need assistance, type:
  ```
  drift-kafka help
  ```
  This will display all available commands and options.
